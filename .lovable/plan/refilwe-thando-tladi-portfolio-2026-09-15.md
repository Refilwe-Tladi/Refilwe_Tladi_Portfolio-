# Refilwe Thando Tladi Portfolio

## Goal
Build a polished, responsive personal portfolio that feels professional, feminine, authentic, and suitable for recruiters and programme assessment.

## What I’ll build
- A sticky responsive navigation with RT monogram and all requested section links.
- A confident first screen with the supplied introduction, two calls to action, and an initials-based profile composition instead of a fictional portrait.
- About, technical skills, soft skills, projects, education, certifications, experience, career interests, reasons to work with Refilwe, and contact sections.
- Exactly three project cards, with the final two clearly marked as editable placeholders.
- Honest education, certification, experience, CV, project-link, and contact placeholders wherever real details are missing.
- A non-submitting contact form that clearly indicates it needs connection details, avoiding fake message delivery.
- Accessible responsive layouts, mobile navigation, smooth in-page navigation, restrained motion, clear focus states, and reduced-motion support.
- Unique portfolio metadata for search and social sharing.

## Visual direction
- Warm off-white base, charcoal typography, blush and dusty-rose surfaces, and deep magenta accents.
- Editorial typography paired with clean readable body text.
- Rounded but restrained cards, thin borders, subtle shadows, generous spacing, and small technology-inspired decorative details.
- No stock imagery, fake portrait, fake statistics, fake testimonials, or inflated proficiency claims.

## Technical approach
- Build the portfolio at `/` with reusable React section and card components.
- Keep the requested sections on one scrolling page so the navigation maps directly to the portfolio presentation.
- Define all colour, spacing, shadow, and type decisions as semantic design tokens in the global stylesheet.
- Use local editable data objects for skills, projects, education, certifications, interests, and contact placeholders.
- Keep CV and unfinished project links visibly disabled until real files or URLs are supplied.
- Verify desktop and mobile layouts, navigation, accessibility basics, and browser console output.
